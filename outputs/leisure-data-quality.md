# Данные для раздела «Чем заняться»

Проверка выполнена по двум переданным Excel-файлам после нормализации.

## Что импортировано

- Основная база: 86 строк.
- Новые места и идеи: 31 строка.
- Всего: 117 записей.
- Активны и доступны гостю: 112.
- Скрыты как `draft`: `IDEA-001`–`IDEA-005`.
- Записей без названия, локации, времени, дороги или возрастных условий среди активных строк нет.

## Что желательно дозаполнить

1. **Фотографии.** В таблицах нет отдельного поля с фотографией активности. Поле карты содержит в основном URL карты. Без фото каталожные карточки используют нейтральные визуальные заглушки.
2. **Конкретная точка старта.** Время дороги указано ориентировочно, но не от конкретного дома гостя. Для точного расписания нужен дом/координаты старта и матрица времени между локациями.
3. **Переезды между местами.** Нет времени Таруса → Поленово, музей → ресторан и других парных расстояний. MVP поэтому собирает не более одной внешней географической группы за день и не придумывает межточечные переезды.
4. **Доступность на дату.** 29 активностей требуют записи, ещё 38 требуют уточнения. Нужны календарь, расписание и подтверждённая доступность; сейчас интерфейс показывает предупреждение и снижает приоритет таких вариантов.
5. **Точная длительность.** У 74 активных записей время задано диапазоном. MVP использует нижнюю границу, чтобы не строить физически невозможный день, но для бронирования нужен выбранный формат/слот.
6. **Маршруты.** Для `route` нужны структурированные километраж, сложность, старт, финиш и точки по пути. Сейчас доступны только общие поля Activity и ссылка/материал.
7. **Услуги и цены.** Для платных услуг нет устойчивой связи с каталогом услуг, цены и API доступности. CTA работает как безопасный демо-сценарий без реальной отправки.
8. **Возраст ребёнка и питомцы.** В Excel есть текстовые ограничения, но нет структурированных минимального/максимального возраста, роста, веса и правил для питомцев.

## Строка, требующая материала

- `NEW-001`: в поле карты указано `welcome-book`, а не URL или файл. Нужна ссылка/asset на конкретные терапевтические сказки.

## Что не попадает гостю

- Все строки `draft` и `disabled`.
- Служебный лист «Кого проверить первым».
- Любая запись без разрешения на добавление/включение в подбор.
